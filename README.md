Relatório de Vendas em Python

Script em Python para processar uma lista de vendas (armazenada em dicionários) e exibir um relatório resumido no terminal com o faturamento por produto, faturamento total e o item de maior receita.

Funcionalidades

Cálculo por produto (calcular_total_venda): Multiplica a quantidade vendida pelo preço unitário de cada item.

Faturamento total (calcular_faturamento): Soma o valor total arrecadado com todas as vendas registradas.

Maior faturamento (encontrar_maior_venda): Identifica qual produto gerou o maior valor total de vendas.

Utiliza apenas recursos nativos do Python, sem necessidade de instalar bibliotecas externas.

Como executar

Certifique-se de ter o Python 3 instalado no computador.

Abra a pasta do projeto no VS Code.

Execute o arquivo relatorio_vendas.py clicando em Play (▷) ou rodando no terminal:

python relatorio_vendas.py


Confira o relatório detalhado exibido diretamente no console/terminal.
